## 🆘 Troubleshooting

### Employee Portal Issues

**Problem:** Can't login
**Solution:** Check credentials, verify Supabase project is active

**Problem:** Data not loading
**Solution:** Check internet connection, verify Supabase credentials

**Problem:** Real-time updates not working
**Solution:** Refresh the page, check Supabase Realtime is enabled

### Admin Desktop Issues

**Problem:** Installer won't run
**Solution:** Right-click → Run as Administrator

**Problem:** App won't open after installation
**Solution:** Check Windows Defender, add to exceptions

**Problem:** Database connection error
**Solution:** Verify Supabase credentials in configuration
